# 📧 Email Spam Classification Using NLP

An **Email Spam Classification System** built using Natural Language Processing (NLP) and Machine Learning to classify emails as **Spam** or **Not Spam (Ham)**. The application provides an interactive interface built with Streamlit, allowing users to enter email text and receive predictions from a trained classification model.

## 🚀 Project Overview

Email spam is a common problem that affects email users through unwanted advertisements, phishing attempts, fraudulent messages, and other unsolicited content.

This project applies NLP techniques to process email text and machine learning to identify patterns associated with spam messages.

The system accepts email text, preprocesses it, transforms it into numerical features, and uses a trained classification model to predict whether the email is spam or legitimate.

## ✨ Features

- 📩 **Email Classification:** Predicts whether an email is Spam or Not Spam.
- 🧹 **Text Preprocessing:** Cleans and prepares email text for analysis.
- 🔤 **NLP Techniques:** Supports text normalization, tokenization, punctuation removal, and stopword removal as implemented in the project.
- 📊 **Prediction Confidence:** Displays the model's confidence or spam probability when supported by the trained model.
- 🎚️ **Adjustable Spam Threshold:** Allows users to adjust the decision threshold if implemented in the application.
- 🖥️ **Interactive Web Interface:** Provides an easy-to-use interface built with Streamlit.
- ⚡ **Real-Time Prediction:** Classifies email text when submitted by the user.
